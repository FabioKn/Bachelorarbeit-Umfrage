Zeit: 0:00

Anleitung

Bedienung der 3D-Umgebung:

  • Maus bewegen: Umschauen
  • Linke Maustaste + Ziehen: Kamera drehen
  • Rechte Maustaste + Ziehen: Kamera zoomen
  • Scrollrad: Zoom in/Zoom out
  • WASD-Tasten: Vorwärts, Rückwärts, Links, Rechts bewegen
  • Info-Button: Unten rechts im Viewer finden Sie einen Info-Button (ⓘ) für detaillierte Bedienungshinweise
  • Kamera-Modi: Über das Kamera-Symbol können Sie zwischen "Orbit Mode" (Umkreisen) und "Fly Mode" (Fliegen) wechseln
  • Desktop/Touch: Oben im Viewer können Sie zwischen Desktop- und Touch-Bedienung umschalten

Prägen Sie sich die Umgebung gut ein. Nach der Erkundung werden Sie weitere Fragen beantworten.
